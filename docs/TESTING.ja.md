# 実機での確認手順（約 30 分）

ユニットテスト（`npm test`）では確認できない、実機・実ブラウザーに依存する部分のチェックリストです。spec-v1.md §6.3 の手順を日本語にし、spec-v2-japanese-paste.md §11 の日本語の貼り付けの項目（6-5、6-8〜6-15）を加えました。設計が前提にしている仮定 A1〜A10 の結果表と、未決の質問への回答欄も付けています。結果は各表の「結果」欄に書き込んでください（HID ログは「コピー」ボタンでテキストとして貼り付けられます）。

## 0. 準備

- Mac（Chrome）＋ NanoKVM-USB ＋ 操作先 Windows。操作先ではテキストエディター（メモ帳など）とブラウザーを開いておく。
- Mac 上で `npm run dev` を実行し、Chrome で **`http://localhost:3001/?debug=hid`** を開く（左下に HID ログが出ます）。
- キーボードメニューで「操作先 OS = Windows」「操作先のキー配列 = 操作先に合わせる（JIS なら JIS）」を確認。
- キーボード → ⌘ キー変換（Mac）→ **オン**（既定）。ナビゲーション / Caps Lock 補正はオン、英数/かな はオフのまま。
- HID ログの読み方: `+Δt 種別 バイト列 デコード`。`kb` の `01 00 06 …` は Ctrl+C、`00 00 …` は全キー解除。`abs` は `x= y= btn= whl=`、`rel` は `dx= dy= btn= whl=`。
- 日本語の貼り付け（6-5、6-8〜6-14）: 操作先は Windows 10 2004 以降または Windows 11、キーボード配列は日本語、IME は Microsoft IME。操作先の Chrome と Edge で `data:text/html,<textarea cols=80 rows=20></textarea>` を開き（この URL も「クリップボードを入力」で打てます）、入力欄をクリックしておく。ネットにつながらない貼り付け先です。
- 貼り付けの設定は既定のまま: 速度 = 標準、「日本語など（ASCII 以外）」= 自動、「ブラウザー経由で開くウィンドウ」= Chrome / Edge のシークレット（Ctrl+Shift+N）、「入力前に操作先の IME をオフにする」= 自動、「操作先の Caps Lock がオンなら自動でオフにする」= オン。初回の確認をもう一度出すには、localStorage の `nanokvm-usb-paste-bridge-intro` を消す。
- 6-15 は Linux の操作先（IBus と Mozc、gedit などの GTK アプリ、Chromium）で行う。操作先 OS = Linux、キー配列は操作先に合わせる。

## 8. 未決の質問（回答欄）

**Q1. 操作先 OS と IME のキーテンプレート**
操作先の Windows のバージョン（winver のビルド番号）とキーボード配列（日本語か英語か）を教えてください。Windows 10 2004 以降 / 11 の日本語配列なら IME オフキー（LANG2）が効くので、「入力前に操作先の IME をオフにする」は既定の「自動」のままにし、Mac の 英数/かな もそのまま IME オフ/オン として使えます（6-9、6-14、A7）。それより古い場合は、MS-IME のキーテンプレートが既定のままか、無変換 → IME オフ、変換 → IME オン を割り当てているかも教えてください。割り当て済みなら「英数/かな → 無変換/変換」をオンにし、「入力前に操作先の IME をオフにする」を「無変換（IME オフに割り当て済みの場合）」にできます。既定のままならどちらも既定のまま（無変換は押しても かなモードが切り替わるだけ）にします。
回答:
