# 実機での確認手順（約 15 分）

ユニットテスト（`npm test`）では確認できない、実機・実ブラウザーに依存する部分のチェックリストです。spec-v1.md §6.3 の手順を日本語にし、設計が前提にしている仮定 A1〜A6 の結果表と、未決の質問への回答欄を付けました。結果は各表の「結果」欄に書き込んでください（HID ログは「コピー」ボタンでテキストとして貼り付けられます）。

## 0. 準備

- Mac（Chrome）＋ NanoKVM-USB ＋ 操作先 Windows。操作先ではテキストエディター（メモ帳など）とブラウザーを開いておく。
- Mac 上で `npm run dev` を実行し、Chrome で **`http://localhost:3001/?debug=hid`** を開く（左下に HID ログが出ます）。
- キーボードメニューで「操作先 OS = Windows」「操作先のキー配列 = 操作先に合わせる（JIS なら JIS）」を確認。
- キーボード → ⌘ キー変換（Mac）→ **オン**（既定）。ナビゲーション / Caps Lock 補正はオン、英数/かな はオフのまま。
- HID ログの読み方: `+Δt 種別 バイト列 デコード`。`kb` の `01 00 06 …` は Ctrl+C、`00 00 …` は全キー解除。`abs` は `x= y= btn= whl=`、`rel` は `dx= dy= btn= whl=`。

## 1. キーテスト（仮定 A1〜A4）

キーボード → ⌘ キー変換 → 「送信できるショートカット」を開く。開いている間は操作先に何も送られません（HID ログにも `kb` 行は増えません）。

| #   | 操作                                          | 期待（キーテストの表示）                                                                                                                       | 結果 |
| --- | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 1-1 | ⌘ を押す → 押したまま C → C を離す → ⌘ を離す | `keydown MetaLeft`、`keydown KeyC`、**`keyup KeyC` は出ない**、`keyup MetaLeft`。「⌘ 押下中に届いた keyup」は 0 回のまま（A1）                 |      |
| 1-2 | Caps Lock を 2 回押す（オン → オフ）          | 1 回目は `keydown CapsLock`、2 回目は `keyup CapsLock` だけが出る（A3）。どちらも `+CapsLock` のあと `timer · CapsLock → -CapsLock` の行が続く |      |
| 1-3 | 英数 を押す、かな を押す                      | `Lang2`、`Lang1`（A4）                                                                                                                         |      |
| 1-4 | 通常ウィンドウで ⌘Tab、⌘Q、⌘W                 | どれが表示されるか記録（A2: 届かない想定）                                                                                                     |      |
| 1-5 | 「全画面にする」を押してから ⌘Tab、⌘Q、⌘W     | どれが表示されるか記録（A2: ⌘W は届く、⌘Tab は届かない想定。⌘Q は不明）                                                                        |      |

全画面を抜けるときは Esc（キーボードロックも解除されます）。終わったらモーダルを閉じます。
